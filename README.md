# Maureen Orkuma: Customer Success and Technical Account Management Portfolio

Simulation portfolio with fictional customers, using Cal.com as the real product. This is not paid client work and not real customer results. I am not affiliated with Cal.com.

## Three end-to-end scenarios
1. **Onboarding:** a 90-day program for a six-clinic healthcare group (success plan, kickoff, technical setup, training,   feedback loop and business review).
2. **Retention:** a health score model and risk playbook to rescue an at-risk 120-seat renewal.
3. **Technical escalation:** a Python and Flask demo that reproduces a webhook failure caused by an expired TLS certificate.

## What is real and what is simulated
**Real:** the tools (HubSpot, Cal.com, Python, Flask, GitHub), the documents, the spreadsheets, the code and the terminal output.
**Simulated:** the customers, the people, the scenario figures and the business results.
